# Image provenance

This project uses only image URLs currently published by the clinic's official website. The hero and clinic photographs are linked directly to those source files because network access was unavailable in the development environment, so local downloading, format conversion, and visual inspection could not be completed.

- `https://drshemdental.com/wp-content/uploads/2023/02/Shem-Dental-clinic.jpg` — official home page image labelled “Shem-Dental-clinic”, used as the clinic image.
- `https://drshemdental.com/wp-content/uploads/2023/02/Shem-Dental-Langata.jpg` — official home page image labelled “Shem-Dental-Langata”, used as a branch image.
- `https://drshemdental.com/wp-content/uploads/2023/02/Jalango-Shem-Dental.jpeg` — published on the official home page, omitted from the design because the subject/permissions could not be inspected.

Official site pages: https://drshemdental.com/ and https://drshemdental.com/our-services/ . The clinic should confirm publication rights, image accuracy, and whether these URLs remain stable. No stock image is presented as clinic photography. No treatment comparison imagery is included.
